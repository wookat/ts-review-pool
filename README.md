# ts-review-pool

2024–2026 时间序列领域顶会论文对比池（供独立盲评使用，仅含客观信息）。

- `papers.csv` — 机器可读（id, subfield, title, authors, venue, year, arxiv_id, doi, pdf_url, summary_zh, in_pool）
- `POOL.md` — 人读版，含子领域覆盖统计

收录范围：ICML / NeurIPS（含 D&B track）/ ICLR / KDD / AAAI / IJCAI / VLDB。venue 经 OpenReview / Crossref / arXiv / PMLR 核实。
