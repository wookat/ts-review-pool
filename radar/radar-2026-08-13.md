### 逐条风险标记

**主力 A（TSFM 污染审计）**

| 条目 | 风险 | 差异化建议 |
|---|---|---|
| TSDS-Toolbox: Measuring Time-Series Dataset Similarity (2608.08119, 08-08) | 低-中 | 数据集相似度工具箱，可被他人用于 train-test overlap 审计。建议：直接把它用作我们审计管线的对照/基线工具并引用，强调我们做的是"预训练语料成员证据 + 污染对性能虚高的因果量化"，不是相似度度量本身。 |
| Evaluation Blindness (2608.02786, 08-03) | 低 | 立场文，把 benchmark 污染列为"评测盲区"之一，无实验方法。引用其作为动机即可，无撞车。 |
| Benchmarking TS Generation for Privacy-Preserving Forecasting (2608.10891, 08-11) | 低 | 用 distance-based 经验隐私风险评合成数据，设定不同（合成数据发布 vs 预训练污染）。related work 中一句话切割。 |
| Ground-Truth Neighborhood Regularization for RL Post-Training of TSFMs (2608.08010, 08-08) | 低 | TSFM 后训练方向，与审计无冲突；可作为"TSFM 生态持续升温"的引证。 |

**主力 B（延迟门控旗舰）**

| 条目 | 风险 | 差异化建议 |
|---|---|---|
| Online Conformal Prediction Beyond Feedback (2608.07139, 08-07) | **中** | 最需要注意：研究"部署预测得不到反馈、只能主动查询标签"的在线共形，与我们"延迟反馈"设定同属反馈受限家族。差异点要写死：他们是分类+预测集+partial monitoring 博弈；我们是预测+延迟到达的真实值+门控自适应更新。建议在 setting 定义处加一张反馈时序图，并引用该文划清"查询式 vs 延迟式"边界。 |
| KReF: Training-Free Retrieval for LTSF and Predictive Uncertainty (2608.06748, 08-07) | 低-中 | 摘要明确点名"sequential 方法在长 horizon 下延迟反馈越来越严重"，说明该痛点已被同行公开表述——我们的动机段不再是独家观察，需引用并强调我们给出的是机制性解法（门控）而非绕开（retrieval）。 |
| REATS: LLM Reasoning-based Ensemble for Adaptive TSF (2608.10149, 08-10) | 低-中 | "样本自适应权重路由"与"门控"表面相似。差异：其权重来自 LLM 推理、无延迟反馈设定、无理论保证。建议命名上避免与 router/ensemble 混淆，突出延迟反馈下的更新时机问题。 |
| Retrieval-Corrected Conformal Prediction for Time Series (2608.10553, 08-11) | 低 | 时序 CP 校准改进，无延迟反馈；入库跟踪即可。 |

**主力 C（多模态时序消融）**

| 条目 | 风险 | 差异化建议 |
|---|---|---|
| Align-RAG: Alignment Is All You Need for TSFM In-Context Learning (2608.05571, 08-06) | **中** | 结论范式与消融文相近："此前归功于可学习融合模块的收益，用免训练对齐即可全部拿回"。若我们的消融也包含"可学习多模态融合组件贡献存疑"类结论，必须引用并区分：他们只针对检索式 TSFM-RAG 的数值模态，我们覆盖文本/多模态输入的系统性消融矩阵。 |
| Decoupling Perception from Description (2608.05238, 08-05) | **中** | 直接指出"LLM 自监督生成文本标注质量封顶"这一多模态对齐核心缺陷，并给出计算接地的构造方案。若我们消融涉及"文本描述监督不可靠"，其为最强相邻工作：建议把它列为对照方法之一，强调我们是诊断性消融（因果归因）而非新数据构造法。 |
| Is Self-Pretraining really useful in medical Time Series? (2608.06122, 08-06) | 低-中 | 同为"质疑式消融"文体（针对 SPT 而非多模态），说明该文体正在流行，投稿时注意时效。方法论无重叠。 |
| TS-RAG (2608.06223) / FM-LLM (2608.11623) / ReasonCast (2608.01875) | 低 | 均为"加模块提性能"方法文，是我们消融的潜在被检对象而非竞争者；可纳入消融对象清单。 |

## 2. 六条线新条目（本期入库 20 条）

### 线 1：TSFM 污染审计相关
1. **TSDS-Toolbox: A Toolbox for Measuring Time-Series Dataset Similarity** — arXiv:2608.08119 (08-08)。统一框架比较时序数据集相似度方法，服务微调源数据选择与基准复现。
2. **Evaluation Blindness: How Silent Measurement Failures Corrupt AI Systems** — arXiv:2608.02786 (08-03)。提出"评测盲区"概念，涵盖训练期基准污染与部署期监控失效。
3. **Benchmarking Time Series Generation Methods for Privacy-Preserving Forecasting** — arXiv:2608.10891 (08-11)。TSTR 协议下联合评估合成时序的预测效用与距离型经验隐私风险。
4. **Ground-Truth Neighborhood Regularization for RL Post-Training of TSFMs** — arXiv:2608.08010 (08-08)。发现 RL 后训练的"次优坍缩"现象并提出邻域正则化。

### 线 2：多模态时序（消融相关）
5. **Align-RAG: Alignment Is All You Need for TSFM In-Context Learning** — arXiv:2608.05571 (08-06)。免训练幅值/相位对齐即可超过已训练检索融合模块（Chronos-Bolt，7 数据集）。
6. **Decoupling Perception from Description** — arXiv:2608.05238 (08-05)。用确定性代码计算多元时序统计量、LLM 仅负责措辞，绕开自监督标注质量封顶。
7. **TS-RAG: Retrieval Augmented Generation for Time Series Forecasting** — arXiv:2608.06223 (08-06)。检索相似历史序列增强时序预测。
8. **FM-LLM: Frequency-enhanced MoE for adapting LLMs to TSF** — arXiv:2608.11623 (08-12)。免提示、频域感知的冻结 LLM 适配框架。
9. **ReasonCast: Towards Explainable TSF with Reasoning** — arXiv:2608.01875 (08-03)。单一响应内同时产出数值预测与文本自解释，附 ReasonTS-Bench。
10. **REATS: LLM Reasoning-based Ensemble Learning for Adaptive TSF** — arXiv:2608.10149 (08-10)。LLM 链式推理作为可解释集成路由器输出样本自适应权重。
11. **Is Self-Pretraining really useful to improve diagnosis in medical Time Series?** — arXiv:2608.06122 (08-06)。系统评估 SPT 在医疗时序上的增益条件。

### 线 3：自适应归一化 / TTA / 延迟反馈
12. **KReF: Training-Free Retrieval for Long-Term TSF and Predictive Uncertainty** — arXiv:2608.06748 (08-07)。检索历史未来片段构成查询局部经验预测分布，规避长 horizon 延迟反馈。
13. **CPDA: Class-Conditional Path Distribution Alignment for Unsupervised TS Domain Adaptation** — arXiv:2608.09193 (08-10)。类条件潜路径分布对齐的非对抗时序域适应。
14. **CAMP: A Cycle-Aware Multi-Scale Patch Mixer for TSF** — arXiv:2608.04051 (08-04)。窗口级自适应周期学习 + 多尺度 patch 混合（周期漂移场景）。

### 线 4：不规则采样
15. **WrapFlow（Enhancing Irregular TSF with Continuous-Time Modeling Framework）** — arXiv:2607.28035 (07-30)。连续时间令牌化直接编码不规则观测，避免 ODE 求解器开销。
16. **GARLIC: Graph Attention-based Relational Learning of MTS in Intensive Care** — arXiv:2608.10969 (08-11)。可学习指数衰减插补 + 时滞摘要图处理 ICU 不规则缺失时序。

### 线 5：在线共形
17. **Online Conformal Prediction Beyond Feedback** — arXiv:2608.07139 (08-07)。预测与查询标签互斥的 OCP 新设定，归约为 partial monitoring 博弈。
18. **Retrieval-Corrected Conformal Prediction for Time Series** — arXiv:2608.10553 (08-11)。检索相似历史残差作局部证据并校正剩余覆盖误差。

### 线 6：live/评测基准
19. **FinVerse: Financial Time-Series Benchmark** — arXiv:2608.03259 (08-04)。11.7 万条金融序列，主张用决策相关指标（如涨跌方向）替代纯误差评测。
20. **Evaluating Generative Time-Series Models on Data with Point Masses** — arXiv:2608.09692 (08-10)。指出 rolling-origin 协议在含点质量数据上可致结论反转，并给出不变性对照。
